# 金秀鉄工 Webサイト

ローカルで確認済みの静的公開データと元ソースを格納しています。

- `publish/`: GitHub Pagesで公開するサイト
- `source-original/`: 元ソース
- `data-backup/`: 記事データのバックアップ
- `tools/`: 静的書き出し・SEO設定
- `README.html`: 詳細な説明

## 公開

Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。公開ワークフローは `.github/workflows/pages.yml` です。

お問い合わせは現在メールアプリを開く方式です。サーバー側送信とCMS・データベース開発は別途対応します。
