金秀鉄工 Webデータ・SEO設定版

2026年10月13日／現行公開版v10を元に作成。今の公開サイトには変更を加えていません。

▶ ローカルでトップページを見る　お問い合わせの仕様を見る

1. 最初に見るもの

  • publish/index.htmlをブラウザで開いてください。全ページ・画像・動画を同梱しています。インターネットなしでも基本表示を確認できます。
  • 推奨：このZIPのルートでpython3 -m http.server 8000を実行し、http://localhost:8000/publish/を開くと、公開に近い形で確認できます。

2. GitHubへ格納・公開

  1. 新規リポジトリに、このZIPルートの内容を格納します。
  2. Settings → Pages → SourceでGitHub Actionsを選択します。同梱ワークフローはpublish/だけを公開します。
  3. Actionsの公開処理が成功したら、発行されたURLで再確認します。
  4. 管理機能や開発ソースは公開成果物に含めません。公開リポジトリの場合はソース自体が閲覧可能になります。保持用ソースを公開したくない場合はprivateリポジトリのPages利用条件をご確認ください。
  5. 金子さんへDNS変更を依頼する前に、独自ドメインをGitHub Pages側に登録・確認してください。

3. お問い合わせ

FormSubmitを通じてWebフォームから送信します。主宛先1名＋CC3名の計4名です。認証画面の後、受付ページへ移動します。主宛先で初回認証メールの承認が必要です。認証と4名の受信確認が完了するまでは運用開始しないでください。実際の送信・受信テストは未実施です。ドメイン変更時も再認証・受信確認を行ってください。秘密鍵は不要です。詳細は tools/contact-setup.md を参照してください。

4. CMS・データ保存

CMSは今回のPages公開対象から外しています。現在掲載中の21記事を固定データとして同梱。旧ブログの全件・全文移行は未完了です。元のD1/R2依存のCMSコードはsource-original/に保存しています。既存CMSをGitHub Pages上でそのまま実行できるという意味ではありません。

5. SEO・AI検索への配慮

  • 本文を最初からHTMLへ収録。JavaScriptを実行しない読み取りにも対応。
  • ページごとにタイトル・説明文・canonical・SNS共有情報を設定。
  • 会社・Webサイト・ページ・パンくず・記事のJSON-LDを設定。
  • お知らせに21個の個別HTML URLと実リンクを用意。
  • sitemap.xml、robots.txt、補助的なllms.txtを収録。
  • 正規URLはhttps://kanehide-tekko.co.jpを前提としています。www版を正規URLにする場合は、tools/seo-config.jsonと公開HTML・sitemap・llmsのURLを揃えて変更してください。
  • 検索結果の表示・順位やAIでの採用は保証できません。llms.txtにも特別なランキング効果を保証しません。
  • 公式ドメイン接続後に、Search Consoleへsitemapを送信し、実URLの認識・構造化データ・HTTPSを確認します。

6. 同梱フォルダ

publish/公開データ／source-original/元の開発ソース／data-backup/記事固定データ／tools/生成スクリプト・SEO設定／.github/Pages公開設定

APIキー・環境変数の秘密・Git認証情報は含めていません。デザインを含む実ブラウザでの最終確認と、GitHub公開・DNS変更は未実施です。
